Examples
========

Below are a few Jupyter notebook examples showing how to use this code to implement the UGME for a simple kinetic model. In this example, transition probability matrices (TPMs) are created from a parameterized simple kinetic model. These kinetic model TPMs are then used to construct the UGME which propagates the TPMs to the selected time.
